# Tauri + React + Typescript

This template should help get you started developing with Tauri, React and Typescript in Vite.

## 起動方法

### 前提

- Webのみ起動（`pnpm dev`）: Node.js / pnpm
- Tauri起動（`pnpm tauri dev`）: Node.js / pnpm / Rust

### セットアップ

```bash
cd apps/desktop
pnpm install
```

### 開発起動（Webのみ）

```bash
pnpm dev
```

### 開発起動（Tauriデスクトップアプリ）

```bash
pnpm tauri dev
```
